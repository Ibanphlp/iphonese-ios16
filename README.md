# iphonese-ios16
iOS 16, on a 4-inch iPhone!
And no, this is not for iPhone 5S.

# What works

- Baseband (cellular functionality is NOT fully tested, as my SE 1 is carrier locked to AT&T)
- Cameras
- Bluetooth
- Wi-Fi
- Apple ID login, native device activation
- SEP (partially)
- Touch ID (partially, loses fingerprint on reboot)

# What does not work

- Device Audio (Audio on Bluetooth works)
- Other things I have not tested.
